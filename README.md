# KARATE WKF COACH 🥋

**Профессиональная система планирования подготовки спортсменов для тренеров по каратэ WKF**

Не просто библиотека упражнений, а полноценная цифровая система многолетней подготовки:

```
Этап подготовки → Год → Период → Месяц → Неделя → День → Тренировка → Блок → Упражнение → Видео
```

Приложение построено вокруг логики **ЧТО → ЗАЧЕМ → КОГДА → КАК**: тренер открывает приложение утром и сразу видит, какая сегодня группа, какая тренировка, какая её цель и какие упражнения выполнять.

## ✨ Возможности (MVP)

- **Главная «Сегодня»** — тренировки дня, ближайшие события, статистика, быстрый доступ
- **Программы подготовки** — 3 этапа (начальная, спортивная группа, совершенствование) с задачами этапов
- **Иерархия планирования** — годовой план → периоды → месяцы (с целями) → недели → дни
- **Конструктор тренировок** — сборка тренировки из блоков и упражнений библиотеки, изменение порядка, настройка времени
- **Режим «Тренировка»** — полноэкранный режим с круговым таймером, переходами между упражнениями, отметками выполнения, видео и заметкой после завершения
- **Библиотека упражнений** — 20+ готовых упражнений, 6 категорий (Кумитэ, Ката, ОФП, СФП, Тактика, Психология), поиск и фильтры
- **Создание упражнений** — полная форма: цель, описание, дозировка, ошибки, варианты, несколько видео (файл или ссылка) с изменением порядка
- **Группы** — создание групп с расписанием по дням недели
- **Спортсмены** — карточки с оценкой 8 навыков (кликабельные шкалы), целями, соревнованиями
- **Календарь** — месячный календарь с тренировками и соревнованиями по этапам
- **Соревнования** — календарь стартов, участники, внесение результатов
- **Аналитика** — выполнение плана, распределение направлений работы, популярные упражнения, средние навыки, прогресс программ

Все данные работают через **рабочие CRUD-операции** (Zustand + localStorage): создание, редактирование, удаление, копирование тренировок сохраняются между сессиями.

## 🎨 Дизайн

- Современный спортивный стиль: **оранжевый** (действия, акценты) + **синий** (навигация, информация)
- Статусы этапов: зелёный / жёлтый / красный
- Тёмная и светлая темы (по системной настройке)
- Мобильный-first: нижняя навигация на телефоне, полное меню на desktop
- Без внешних CDN — все шрифты и иконки локальные, работает без VPN

## 🚀 Запуск

```bash
npm install
npm run dev
# откройте http://localhost:3000
```

Приложение сразу работает с демо-данными — Supabase не требуется. Кнопка ⟳ в шапке сбрасывает данные к демо-состоянию.

### Продакшн-сборка (статический сайт)

```bash
npm run build
```

Готовый сайт появляется в папке `out/` — это обычные HTML/CSS/JS файлы.
Их можно загрузить на **любой хостинг** (Timeweb, reg.ru и т.д.) через WinSCP/FTP
в папку сайта (обычно `public_html`). Node.js на сервере не нужен.

### Подключение Supabase (опционально)

1. Создайте проект на supabase.com
2. Выполните `migrations/001_initial_schema.sql` и `002_seed_data.sql` в SQL Editor
3. Создайте `.env.local`:

```env
NEXT_PUBLIC_SUPABASE_URL=https://your-project.supabase.co
NEXT_PUBLIC_SUPABASE_ANON_KEY=your-anon-key
```

Клиент и CRUD-хелперы уже готовы в `lib/supabase.ts`.

## 🗺 Основной сценарий

1. Главная → «Начать тренировку» → полноэкранный режим с таймером
2. Программы → этап → год → месяц (цели) → неделя → день → тренировка
3. Конструктор → группа + тема + блоки + упражнения из библиотеки → сохранить
4. Упражнения → «+ Добавить» → форма с видео → используется в любых тренировках
5. После тренировки → отметки выполнения → заметка тренера → аналитика
